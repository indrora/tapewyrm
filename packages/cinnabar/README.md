# cinnabar

A viewer that shows a TWRF capture or TWTI/TWTZ image the way the drive saw it, track by track and segment by segment, as a stack of lanes: flux, records, fields and bytes.

Run its lint, type checks and tests from the repository root:

```sh
just check cinnabar cinnabar
```
